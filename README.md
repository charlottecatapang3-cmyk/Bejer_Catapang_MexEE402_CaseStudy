## WHAT WE LEARNED

### Ch1_2_3: Introduction to Preprocessing, Exploring and Cleaning Data

<p align="justify">
We learned that preparing and checking the data is an important part of machine learning. We learned that raw data can have missing values, unnecessary information, or other problems that need to be fixed before using it. We also learned that exploring the dataset first helps us understand the data and know what needs to be cleaned. What surprised us was that a lot of preparation is needed before data can be used for analysis and machine learning.
</p>

### Ch4: Transformation, Feature Engineering and Encoding

<p align="justify">
We learned that we can change existing data or create new features to make the data more useful. We learned how binning can group numerical values into categories and how interaction features can show relationships between variables. We also learned that categorical data needs to be encoded based on the type of category. What surprised us was that a simple calculation like Lemonade per Degree can help us understand the relationship between temperature and sales in a different way.
</p>

### Ch5: Scaling and Normalization

<p align="justify">
We learned that different features can have very different ranges of values, which can affect some machine learning models. Scaling helps make the values more comparable and prevents larger numbers from having too much influence. We also learned the difference between StandardScaler and MinMaxScaler. What surprised us was that the size of the numbers can affect a model even if the features are both important.
</p>

### Ch6: Outlier Detection

<p align="justify">
We learned that an outlier is a value that is very different from most of the other values in a dataset. We learned how the Z-score and IQR methods can be used to find unusual values. We also learned that an outlier should not always be removed because it can still be a valid part of the data. What surprised us was that a value that looks unusual may not always be considered an outlier depending on the method used.
</p>

### Ch7: Feature Selection

<p align="justify">
We learned that using all the available features is not always necessary for machine learning. Feature selection helps us choose the features that are more useful and remove unnecessary ones. We also learned that the Filter Method, RFECV, and LassoCV may select different features because they use different methods. What surprised us was that the same dataset can have different selected features depending on the method used.
</p>

### Ch8: Constructing a Preprocessing Pipeline

<p align="justify">
We learned that different preprocessing steps can be combined into one organized process. The conveyor-belt idea helped us understand how data goes through each step in the correct order before being used by a model. We also learned that pipelines can make the process more consistent, efficient, and easier to repeat. What surprised us was that putting all the steps into one pipeline can help prevent mistakes and missed steps.
</p>

### Ch9: Full Pipeline and Visualization

<p align="justify">
We learned that different preprocessing techniques can be combined into one complete process for both numerical and categorical data. We learned how to handle missing values, group numerical values into categories, and create visualizations after preprocessing. We also learned that graphs can help us understand patterns and relationships in the data more easily. What surprised us was that preprocessing not only prepares the data for machine learning but also makes the data easier to understand through visualizations.
</p>
